# Mitigation & Hardening

## Mitigazioni
- minimizzare dati persistenti
- ridurre privilegi e scope
- evitare segreti lato client
- applicare CSP e allowlist
- introdurre conferme esplicite per azioni sensibili
- firmare webhook e validare origine

## Hardening
- token brevi e revocabili
- segmentazione dati
- cache strategy conservativa
- policy browser e endpoint
- logging difensivo
- report di sicurezza periodici
